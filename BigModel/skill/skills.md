# Antigravity Skills 学习笔记

## 1. 技能是什么
- 技能是基于目录的软件包
- 目录内包含定义文件 `SKILL.md`
- 可选支持资源：脚本、参考资料、模板

补充：技能的目标是让流程更短、更稳、更可复用。只保留必要内容，避免冗长说明。

## 2. 按需拓展机制
- 技能通常按需调用或按任务触发，避免无关内容干扰，减少不必要的上下文负担

## 3. 不只是指令，还能执行操作
- 技能不仅是提示词，还可配合工具与流程执行操作
- 可组合多步骤，形成可复用的任务流程
- 是否能执行本地或外部网络操作取决于工具与权限
- 目标是把任务从描述推进到完成

## 4. 创建技能的具体操作
1. 新建技能目录，例如 `skills/your-skill-name/`
2. 在目录内创建 `SKILL.md`，写明用途、触发方式、输入输出、步骤与限制
3. 需要的话添加支持资源：`scripts/`、`references/`、`templates/`
4. 用一个最小示例验证可用性，然后再逐步扩展

## 5. SKILL.md 最小模板
```md
# Skill Name

## 用途
一句话说明这个技能解决什么问题。

## 触发
触发关键词或触发场景。

## 输入
必填与可选输入说明。

## 输出
产出物或结果说明。

## 步骤
1. 步骤一
2. 步骤二
3. 步骤三

## 限制
边界条件、权限要求、不可做的事。
```
